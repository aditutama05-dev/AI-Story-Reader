Perpustakaan cerita

Kelompokkan karya secara terpisah: Seri → Arc → Volume → Chapter atau bagian seperti Interlude, Ending, dan Epilogue. Simpan catatan manual serta fakta kontinuitas terstruktur (tokoh, relasi, lokasi, istilah, kejadian, konflik) dengan kutipan sumber. Data disimpan di browser perangkat ini. Gunakan ekspor cadangan untuk memindahkannya ke perangkat lain.

Aksesibilitas & kenyamanan membaca

Kontrol ini membantu pengguna low vision dan pengguna keyboard. Seluruh teks narasi tetap tersedia sebagai teks yang bisa dibaca TalkBack atau pembaca layar lain. Website ini tidak dapat membaca layar aplikasi lain atau mengambil screenshot perangkat secara diam-diam.

Keamanan koneksi API

Token akses hanya disimpan sementara di sesi browser. Kunci provider AI tetap berada di server dan tidak pernah dimasukkan di sini.

1. Impor sumber cerita

Website yang memblokir akses otomatis atau memerlukan login mungkin tidak bisa diimpor. Gunakan salin-tempel sebagai alternatif.

Format: EPUB, PDF berbasis teks, TXT, Markdown, HTML, DOCX. PDF hasil scan memerlukan OCR.

2. Baca manga / manhwa dari gambar

Belum ada halaman dipilih. Untuk gambar, gunakan tombol Naikkan/Turunkan agar urutan baca benar sebelum OCR.

Pilih maksimal 30 halaman JPG/JPEG, PNG, atau WEBP. Atur urutan gambar di antrean dengan tombol Naikkan/Turunkan; halaman dalam satu arsip CBZ/ZIP diurutkan berdasarkan nama file. Jangan campur arsip dengan upload gambar. Gunakan model AI yang mendukung gambar/vision. Hasil panel, dialog, pikiran, caption, dan SFX akan dipetakan ke sumber agar bisa ditinjau sebelum narasi.
