Perpustakaan cerita

Kelompokkan karya secara terpisah: Seri → Arc → Volume → Chapter atau bagian seperti Interlude, Ending, dan Epilogue. Data disimpan di browser perangkat ini. Gunakan ekspor cadangan untuk memindahkannya ke perangkat lain.

\n

Aksesibilitas & kenyamanan membaca

Kontrol ini membantu pengguna low vision dan pengguna keyboard. Seluruh teks narasi tetap tersedia sebagai teks yang bisa dibaca TalkBack atau pembaca layar lain. Website ini tidak dapat membaca layar aplikasi lain atau mengambil screenshot perangkat secara diam-diam.

Keamanan koneksi API

Token akses hanya disimpan sementara di sesi browser. Kunci provider AI tetap berada di server dan tidak pernah dimasukkan di sini.

1. Impor sumber cerita

Website yang memblokir akses otomatis atau memerlukan login mungkin tidak bisa diimpor. Gunakan salin-tempel sebagai alternatif.

Format: EPUB, PDF berbasis teks, TXT, Markdown, HTML, DOCX. PDF hasil scan memerlukan OCR.

2. Baca manga / manhwa dari gambar

Pilih maksimal 30 halaman JPG, PNG, atau WEBP. Gunakan model AI yang mendukung gambar/vision. Hasil transkripsi akan dimasukkan ke editor chapter dan tetap bisa diedit sebelum dibuat narasi.

Audio MP3 satu chapter penuh

Buat satu file MP3 untuk seluruh narasi chapter. Pembuatan audio memerlukan koneksi server ke layanan TTS.

Unduh MP3

TalkBack dapat membaca teks narasi di bawah ini seperti teks web biasa. Tombol TTS adalah pilihan tambahan; suara yang tersedia bergantung pada Android/browser dan paket suara yang terpasang.

API key tetap berada di environment backend, tidak dikirim ke browser dan tidak disimpan di repository.
